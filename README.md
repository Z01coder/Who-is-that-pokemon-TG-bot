## О проекте

![Превью](assets/1a.webp)

![Демонстрация](assets/1.gif)

Who is that Pokemon TG-Bot - это Telegram-бот, который использует [PokeAPI](https://pokeapi.co/) для получения информации о покемонах. Бот позволяет пользователям искать покемонов по имени или ID, получать случайных покемонов и просматривать их изображения с информацией о типах.

<details>
  <summary><strong>Цели и задачи проекта</strong></summary>

**Цели:**
* Создать функционального Telegram-бота для работы с PokeAPI
* Продемонстрировать интеграцию с внешним API через асинхронные запросы
* Реализовать удобный интерфейс взаимодействия с пользователями
* Обеспечить надежную обработку ошибок и валидацию данных

**Ключевые задачи:**
* Интегрировать бота с PokeAPI для получения данных о покемонах
* Реализовать поиск покемонов по имени или ID
* Добавить функцию получения случайного покемона
* Внедрить FSM (Finite State Machine) для управления диалогами
* Реализовать валидацию пользовательского ввода
* Настроить логирование всех операций бота
* Обеспечить обработку ошибок и таймаутов при запросах к API
* Использовать переменные окружения для безопасного хранения токена

</details>

<details>
  <summary><strong>Результаты</strong></summary>

**Реализованная функциональность:**
* Поиск покемона по имени или ID (от 1 до 1010)
* Получение случайного покемона из базы данных PokeAPI
* Отправка изображений покемонов с информацией о типах
* Интерактивное меню с inline-кнопками
* Валидация пользовательского ввода (проверка длины, формата, диапазона ID)
* Обработка ошибок API и таймаутов
* Логирование всех операций бота
* Управление состояниями диалога через FSM

**Созданные компоненты:**
* Основной файл `main.py` с логикой бота
* Функция `get_pokemon_info()` для асинхронных запросов к PokeAPI
* Класс состояний `PokemonStates` для управления диалогами
* Функция валидации `validate_pokemon_input()` для проверки ввода
* Обработчики команд и callback-запросов
* Система логирования с записью в файл и консоль

</details>

<!-- GETTING STARTED -->
<details>
  <summary><strong>Начало работы</strong></summary>

Инструкции по установке и запуску проекта локально.

### Требования

Для работы с проектом необходимо установить:

* Python 3.x
  ```sh
  # Проверьте версию Python
  python --version
  ```

### Установка

Ниже приведены инструкции по установке и настройке бота.

1. Клонируйте репозиторий
   ```sh
   git clone https://github.com/Z01coder/Who-is-that-pokemon-TG-bot.git
   cd Who-is-that-pokemon-TG-bot
   ```

2. Создайте виртуальное окружение (рекомендуется)
   ```sh
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # Linux/Mac
   source venv/bin/activate
   ```

3. Установите зависимости
   ```sh
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` в корне проекта
   ```sh
   # Создайте файл .env и добавьте в него:
   BOT_TOKEN=ваш_токен_бота_от_BotFather
   ```

5. Получите токен бота:
   - Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
   - Отправьте команду `/newbot` и следуйте инструкциям
   - Скопируйте полученный токен в файл `.env`

6. Запустите бота
   ```sh
   python main.py
   ```

7. Откройте Telegram и найдите вашего бота по имени, которое вы указали при создании

</details>

<!-- USAGE EXAMPLES -->
<details>
  <summary><strong>Использование</strong></summary>

Бот предоставляет следующие команды и функциональность:

### Основные команды:

1. **`/start` или `/help`**
   - Запускает бота и показывает главное меню
   - Отображает inline-кнопки для выбора действия

2. **🔍 Поиск покемона**
   - Бот запрашивает имя или ID покемона
   - Поддерживает поиск по имени (например: "pikachu", "charizard")
   - Поддерживает поиск по ID (от 1 до 1010)
   - Отправляет изображение покемона с информацией о его типах

3. **🎲 Случайный покемон**
   - Бот автоматически выбирает случайного покемона из базы данных
   - Отправляет изображение и информацию о покемоне
   - Не требует ввода от пользователя

### Особенности:

- **Валидация ввода**: проверка корректности имени или ID перед запросом к API
- **Обработка ошибок**: информативные сообщения при отсутствии покемона или ошибках API
- **Таймауты**: защита от зависания при проблемах с сетью (таймаут 10 секунд)
- **Логирование**: все операции записываются в файл `bot.log` для отладки
- **Асинхронность**: быстрая работа благодаря асинхронным запросам к API

</details>
